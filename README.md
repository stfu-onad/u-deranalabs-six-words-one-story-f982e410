# Six Words, One Story

Entry for the make.fun bounty
[u-deranalabs-six-words-one-story-f982e410](https://make.fun/bounty/u-deranalabs-six-words-one-story-f982e410)

`main.py` (Python 3.13, standard library only) writes one complete story in
exactly six words to `/output/entry.txt`:

> He came home. Nobody remembered him.

Run it:

```sh
python3 main.py
```

Then read `/output/entry.txt` — 6 words, 36 characters, one line.
